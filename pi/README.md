# Raspberry Pi HIL runner

`hil_runner.py` plays one load profile (generated by `matlab/06_phase2_hil_profiles/run_phase2_batch.m`)
into a single cell through the ATORCH DL24P, one second at a time, and logs what the cell did.

Every second it reads the load (voltage, current, power), looks up `P_cell_W` for that second,
sends `I_cmd = P_cell_W / V_measured` (clamped to 0.2–8 A; 0 A when the vehicle is stopped or
braking) and writes one CSV row with measured and commanded values side by side.

## Setup (Raspberry Pi OS)

1. Enable 1-Wire: `sudo raspi-config` → Interface Options → 1-Wire → enable, then reboot.
2. Get the DL24P USB-HID driver module `dl24p` from
   <https://github.com/sophusand/atorch-dl24p-python> and follow that repository's install
   instructions so that `import dl24p` works.
3. Copy the profile CSVs into `pi/profiles/`.

## Use

```bash
python hil_runner.py --list-sensors        # find the two DS18B20 IDs, put them in SENSORS
python hil_runner.py --selftest            # first time only, with any charged cell (~6 min)
python hil_runner.py profiles/A1_idc_flat.csv --cell MJ1-01 --note "day 1 overnight"
```

Logs are written to `pi/logs/` (one CSV + one JSON summary per run; not tracked in git).

## Settings to check before the campaign (top of `hil_runner.py`)

* `V_END = 3.20` — must match `C.cell.V_end` in `phase2_config.m`.
* `SENSORS` — the two DS18B20 IDs.
* `ZERO_MODE` and `DEADMAN_MODE` — choose after `--selftest` steps 3 and 4.

Note: the DL24P library is tested on Windows and macOS, not on Linux — run `--selftest` first.
Train models on the measured current (`I_meas_A`), never on the command: the load takes about
2 s to follow a current step.
